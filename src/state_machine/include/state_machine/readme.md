# 状态机设计说明

## 状态机成员：
- IDLE STATE：空闲状态，等待开始指令
- CHASSIS STATE：底盘模式，进行底盘相关操作
- ARM STATE：机械臂模式，进行机械臂相关操作
- MENU STATE：菜单模式，进行菜单相关操作
- POLE STATE：杆子模式，进行杆子相关操作
- VISION TASK STATE：视觉任务模式，进行视觉任务相关操作
- EMERGENCY STATE：紧急状态，进行紧急相关操作

### IDLE STATE子模块：
- 全部进程启动后优先进入该状态，只能等待扳机进入菜单模式，不可做任何操作，防误触

### MENU STATE子模块：
- 左扳机进入菜单模式，右摇杆上下选择菜单选项，优先松开扳机进入对应状态，菜单选项包括底盘模式、机械臂模式、紧急模式、视觉任务模式、空闲模式、回收臂模式。

### ARM STATE子模块：
- 进入机械臂模式后，通过左摇杆控制x、y轴运动，右摇杆控制z轴和yaw，上下左右按键控制机械臂pitch，双扳机扣动控制机械臂抓取，组合指令进行预设动作

### POLE STATE子模块：
- 进入杆子模式后，确保车子停在高地侧，左摇杆正常控制底盘运动，右扳机控制杆子旋转，杆子旋转程度和扳机扣动程度正相关，确保杆子已经将能量单元收回后，此时扣动左扳机锁定杆子，之后便可松开右扳机。并选择退出杆子模式。

### VISION TASK STATE子模块：
- 进入视觉任务模式后，类比ARM STATE的控制方式，左摇杆控制机械臂x、y轴运动，右摇杆控制机械臂z轴和yaw，上下按键控制机械臂pitch，调整到视觉模块提示目标锁定之后，可向裁判申请开启视觉任务，此后底盘待机直到订阅到视觉任务完成的信息。

### EMERGENCY STATE子模块：
- 进入紧急模式后，底盘和机械臂立即停止一切动作，等待用户选择退出紧急模式，退出后回到之前的状态

### CHASSIS STATE子模块：
- 进入底盘模式后，默认进入HOME STATE，发车处也是以HOME STATE待命。大部分情况下操纵左摇杆控制底盘运动，具体情况参考如下子模块列表。

#### CHASSIS MODE子模块：

- HOME
- NORMAL DETECTION
- CYLINDER SUBMISSION
- CUBE SUBMISSION
- CYLINDER COLLECTION
- CUBE COLLECTION
- UNDER BRIDGE
- BALL SUBMISSION

###### 子模块切换说明
- 通过LB按键进入子菜单，实现方式类似于MENU STATE进入对应状态，进入子菜单后通过右摇杆上下选择子模块选项，优先松开LB按键进入对应子模块状态。每个子模块状态内都有返回HOME状态的指令，HOME状态作为中转可以进入任意子模块状态。

##### 子模块功能解析：
- HOME：
  - 简述：底盘模式起始状态
  - 指令：仅使用左摇杆控制底盘运动
    - 摇杆：左摇杆控制底盘
    - 按钮：无
    - 扳机：无
    - 组合指令：双扳机扣动折叠机械臂，进入发车前状态
  - 视觉：不进行视觉
  - 机械臂姿态：双扳机扣动折叠机械臂，进入发车前状态
  - 可跳转状态：NORMAL DETECTION、CYLINDER SUBMISSION、CUBE SUBMISSION
  - 来自状态：任意状态（由于不改变当前姿态，可作为任意状态的中转）
  
- NORMAL DETECTION：
  - 简述：基础检测状态，进行方块、能量单元检测和解算，得出结果会反馈到UI界面，等待确认指令进入对应抓取状态
  - 指令：使用左摇杆控制底盘运动，机械臂上的视觉模块可以稳定看见四周，用右摇杆控制yaw旋转，调整视觉模块的朝向
    - 摇杆：左摇杆控制底盘、右摇杆控制机械臂上的视觉模块的yaw旋转
    - 按钮：A键确认检测结果，进入对应抓取状态、B键重新进行检测、X键进入临时机械臂控制模式，可用左摇杆控制机械臂的前后伸缩，右摇杆左右控制机械臂的yaw旋转前后控制pitch，Y键返回NORMAL DETECTION状态
    - 扳机：无
    - 组合指令：无
  - 视觉：运行用单目深度预测模型训练的yolo模型，进行方块、能量单元检测和解算，得出结果会反馈到UI界面，等待确认指令进入对应抓取状态
  - 机械臂姿态：默认竖直，使得视觉模块可以稳定看见四周，可通过临时机械臂控制模式调整机械臂姿态
  - 可跳转状态：HOME、CYLINDER SUBMISSION、CUBE SUBMISSION
  - 来自状态：HOME
  - 备注：由于视觉模块的视野较窄，且需要保持稳定，因此在该状态下机械臂默认竖直，无法调整高度和左右旋转，仅能通过右摇杆调整yaw旋转前后控制pitch，进入临时机械臂控制模式后可以调整机械臂姿态以适应不同环境

- CYLINDER SUBMISSION：
  - 简述：能量单元提交状态，进行能量单元的抓取和提交
  - 指令：使用左摇杆控制底盘运动，先识别洞口位置，接收按键指令进行预设动作抓取能量单元并摆放至提交洞口附近
    - 摇杆：左摇杆控制底盘，右摇杆控制机械臂上的视觉模块的yaw旋转，调整视觉模块的朝向。能量单元摆放在洞口附近后可以通过左摇杆控制机械臂前后左右移动，右摇杆左右控制机械臂的yaw旋转前后控制pitch调整机械臂姿态以适应不同环境。左右按键可以微调机械臂左右位置，前后按键可以微调机械臂前后位置
    - 按钮：A键确认检测结果，进入对应抓取状态、时刻进行检测、放置到洞口附近之后等待下次按A键确认释放，按B可以放回原位置
    - 扳机：无
    - 组合指令：放在洞口后，双扳机扣动松开爪子，完成提交
  - 视觉：先识别洞口位置，发送识别到的标签，通过按键确认后进入下一步骤。
  - 机械臂姿态：根据视觉模块识别到的洞口位置进行预设动作抓取能量单元并摆放至提交洞口附近，放在洞口后，双扳机扣动松开爪子，完成提交
  - 可跳转状态：HOME
  - 来自状态：HOME、UNDER BRIDGE

- CUBE SUBMISSION：
  - 简述：方块提交状态，进行方块的抓取和提交，细节参考CYLINDER SUBMISSION状态

- CYLINDER COLLECTION：
  - 简述：能量单元收集状态，进行能量单元的抓取和收集
  - 指令：使用左摇杆控制底盘运动，先识别能量单元位置，接收按键指令进行预设动作抓取能量单元并放入储存位置
    - 摇杆：无
    - 按键：无
    - 扳机：无
    - 组合指令：从NORMAL DETECTION状态进入后，等待双扳机确认指令进入抓取，抓到后沿预设动作放回到储存位置
  - 视觉：运用NORMAL DETECTION状态的视觉模块识别能量单元位置，发送识别到的标签，通过双扳机确认后进入下一步骤。
  - 机械臂姿态：根据视觉模块识别到的能量单元位置进行预设动作抓取能量单元并放入储存位置
  - 可跳转状态：HOME
  - 来自状态：NORMAL DETECTION

- CUBE COLLECTION：
  - 简述：方块收集状态，进行方块的抓取和收集，细节参考CYLINDER COLLECTION状态

- UNDER BRIDGE：
  - 简述：过隧道状态，进行过隧道相关操作
  - 指令：接收按键指令进行预设动作过隧道
    - 摇杆：无
    - 按键：A键进入过隧道状态，执行预设动作过隧道，按B键返回HOME状态
    - 扳机：无
    - 组合指令：无
  - 视觉：不进行视觉
  - 机械臂姿态：执行预设动作过隧道
  - 可跳转状态：HOME
  - 来自状态：HOME

- BALL SUBMISSION：
  - 简述：球提交状态，进行球的提交
  - 指令:行进到提交箱附近之后，关闭挡板、提升存储箱位置、前进、释放挡板、合拢挡板、放下存储箱
    - 摇杆：左摇杆控制底盘运动
    - 按键：A键进入球提交状态，执行预设动作提交球，按B键返回上一步
    - 扳机：无
    - 组合指令：双扳机扣动，陆续执行预设动作步骤
    - 视觉：不进行视觉
    - 机械臂姿态：执行预设动作提交球
    - 可跳转状态：HOME
    - 来自状态：HOME
